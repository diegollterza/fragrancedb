# FragranceDB
A simple app to fetch fragance data and personal rate.

## Features

- Fetch fragrance data from Fragrantica
- Store personal user rate.
- Simple and intuitive CLI interface
- Support for fragrance comparisons

## Installation

```bash
git clone https://github.com/yourusername/fragrancedb.git
cd fragrancedb
pip install -r requirements.txt
```

## Usage

```bash
python fragrancedb.py --help
```
